# @civora/ui

Composants Svelte construits uniquement sur `docs/design/tokens.css`. Charger le skill `ui-design` avant d'en ajouter un.

Composants à créer en P1 et P2, dans cet ordre :

1. `Skeleton` (lignes, avatar, carte, ligne de tableau)
2. `Button` (principal, secondaire contour, encre, fantôme) ; une seule action principale par vue
3. `Field`, `Search` (pilule), `Select`, `Switch` (role="switch", état Oui ou Non écrit, aide en dessous)
4. `Tabs` avec compteurs, `Segmented` (bascule de vue)
5. `FilterBuilder` (pastilles champ, opérateur, valeur, reliées par ET ou OU)
6. `BulkBar` (barre d'actions groupées)
7. `DataTable` (cases à cocher, étiquettes, cotisations sur 12 mois, pagination)
8. `EntityCard` (organes : canaux, responsables cerclés, pile d'avatars, statut, échéance, état sélectionné inversé)
9. `SidePanel` (édition sans quitter la liste, mode simple)
10. `NavRail` et `SubNav`
11. `Avatar` et `AvatarStack` (duotone, « +N »)
12. Objets : `MemberCard` (motif de sécurité), `Ticket` (bord perforé), `Stamp` (encre), `Ballot`
